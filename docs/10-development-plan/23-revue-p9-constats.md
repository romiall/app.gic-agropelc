# Revue adverse du code de P9 (P9-25) — constats

> Revue menée le 26/10/2026 sur la branche `claude/p9-integration`, après l'intégration de P9 et une suite complète verte sur une base neuve (serveur 2 020 tests). Six relecteurs, un par domaine, chacun chargé de réfuter ses propres constats avant de les rendre. **État du traitement** : voir le § 7 en fin de fichier. Verdicts : CONFIRMÉ (test temporaire, mesure ou trace dans le code), PLAUSIBLE (non démontré). Gravités : BLOQUANT, MAJEUR, MINEUR.

> **Revue complétée le 28/10/2026** : les cinq domaines restants (alertes, notifications et notes, explorateur, tableaux de bord, plateforme) ont été relus, un relecteur chacun, chacun chargé de réfuter ses propres constats avant de les rendre ; **39 constats nouveaux** (14 MAJEUR, 25 MINEUR). Aucun n'a été vérifié par un second lecteur : le verdict PLAUSIBLE n'est pas un défaut établi, à rejouer contre le code avant de corriger. Les neuf tests sautés (`ctx.skip`) sont traités par EP-4.
